# 图结构与接口说明（2026-10-25）

最终业务及恢复语义以《项目架构书.md》和《使用说明.md》为准。

新增 AgentCore 的 search_items/query_updates/get_item/get_source_status/get_preferences/update_preferences/undo_preference_change 是独立 typed Python 接口，不调用个人简报 LangGraph。查询先检索本档案允许的保留数据，最多一次逻辑模型选证据，零正式推荐／反馈；完整输入输出与 CLI 见 [Agent 核心接口](Agent核心接口.md)。网页与 Agent 设置共用 SettingsService、目标修订和可撤销事务；SQLite v4 在旧库迁移前备份。

## LangGraph

START → run → END。run 顺序完成 collect、prepare、preferences、select、persist。保留 LangGraph 返回 `.invoke({})` 的 Python 协议，阶段失败在 SQLite/run.json 中记录。不启用模型循环或 checkpointer。

```python
from info_agent.workflow import build_briefing
result = build_briefing(profile, model=fake_model, fetcher=fake_fetcher,
                        store=temp_store, clock=fixed_clock).invoke({})
```

profile 可用旧四字段字典；统一通过 Profile 校验。model、fetcher、store、clock 均可注入。默认 Store 是本地正式数据库，测试应传临时存储。fetcher 返回 Article（或兼容字典）列表，clock 返回带时区 datetime。

## RSS 与模型

按 sources 请求关键词 `/bilibili/vsearch/{keyword}/pubdate`、UP `/bilibili/user/video/{uid}`、关注 `/bilibili/followings/video/{uid}`；最多 16 个订阅各请求一次，默认 15 秒超时（可调至 40）、2 MiB 上限，绕过代理。不修改 RSSHub 服务。parse_feed 拒绝 DTD、错误页与非法链接，提取 Length/category/播放器已有别名，无额外视频请求。

一次结构化模型请求返回有限 Selection 短名单。模型来源信息不得覆盖原候选；非法输出失败，无模型修复。生产 include_raw 获取 token，HTTP hook 统计实际 SDK 尝试与重试。未提供用量为 null。

## 文件与命令

SQLite 保存事实记录，JSON/Markdown 可由 recover 再生。候选在筛选前保存；正式报告与推荐一次事务提交后导出文件。导出失败时可能已经正式登记推荐，可恢复文件，不会重复登记。

保留 main.py 点击运行及 `--preview`、`--show`、`--profile`。新增 feedback、preferences、recover、backup、import-legacy 终端子命令；全局参数位于子命令前。反馈支持 useful/not_useful/later、可选 reason、幂等 key 和按事件 ID 撤销。完整例子见使用说明。

多来源、封面、稳定兴趣身份与 schema v2 迁移详见《前端对接约定-多来源与封面.md》和 v3 架构书；网页能力标志均已实现，不表示具体远端账号在线可用。
