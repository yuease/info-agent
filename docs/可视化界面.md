# 本地可视化界面

更新日期：2026-10-25。Agent 查询核心为独立 Python／CLI，网页保留原设计，没有新增 Agent 插件、MCP 或查询面板；见 [Agent 核心接口](Agent核心接口.md)。

## 启动与关闭

保留原有 `main.py` 生成简报入口，新增 `main_gui.py` 网页入口。在编辑器选择现有 conda agent 解释器运行 `main_gui.py`，或在项目目录执行：

```powershell
& D:\Anaconda3\envs\agent\python.exe -m info_agent.web
```

默认打开 `http://127.0.0.1:8765`。页面关闭不停止服务，服务终端关闭或 Ctrl+C 才会停止。生成中请保持服务运行；中断后的记录由原有恢复逻辑处理。端口不可用时指定 `--port 8766`。`--no-browser` 只启动服务，不自动打开浏览器。

网页无构建步骤、无需 Node 或新增 Python 依赖。Python 标准库 HTTP 服务绑定 127.0.0.1，只供本机个人使用，不作为外网生产服务器。

## 页面功能

### 我的简报

- “生成新简报”运行已有工作流，会使用当前配置的模型。
- “仅采集预览”获取 RSS 和候选，不调用模型，不登记推荐历史。
- 生成过程在独立线程运行；页面轮询状态，不阻塞历史浏览。
- 同时只允许网页发起一个任务；生成期间禁止通过网页保存设置。
- 卡片包含原始来源、时长、标签、摘要、推荐理由、建议行动和探索标记。
- “有用／没用／暂时不想看”直接保存反馈；“没用”之后可以选择原因；“撤销”复用原有事件撤销语义。
- 导出下载原有 Markdown 简报。预览或失败运行不伪装成正式简报。

### 历史记录

显示 SQLite 中最近 100 次运行，包括正式简报、空结果、预览和失败状态。选择记录查看内容与运行诊断。历史显示不限稳定兴趣档案；同一明确兴趣和特征解释规则下换关键词／来源仍可评价旧推荐，不同目标保持隔离。

仅存在于旧 JSON 目录而未导入 SQLite 的历史不会自动出现。需要时使用已有 `import-legacy` 命令，确认是否为正式发布后再导入，不因浏览网页自动改变推荐冷却记录。

### 偏好学习

展示当前上下文的有效反馈数、有用率、激活偏好和版本。不足以激活偏好时明确说明，而不是显示虚构数据。后台学习沿用已有算法，不额外调用模型。关闭学习开关表示不应用学习权重，现有后端仍可保留反馈和汇总证据。

### 兴趣设置

“订阅来源”配置关键词、UP UID 和关注账号 UID；“兴趣设置”编辑兴趣描述、推荐数量、时长上限、探索比例、重复推荐间隔与学习开关。保存时复用 Profile 校验并采用原子文件替换，保留 RSSHub 地址、模型配置及未展示的高级参数。

兴趣修改方式可选“调整同一目标，延续学习”（默认）或“切换目标，隔离旧学习”，由使用者明确表达，不调用模型判断。网页与 Agent 共用 SettingsService、版本／快照冲突检查及审计事务。保存响应新增 change_id/version/goal_id，长期兴趣／关键词撤销可用 Agent Python／CLI；暂未增加网页变更历史面板。当前规则目录已加入独立“过滤明显促销”开关，不按品牌名直接过滤；旧规则列表不自动启用新规则。源码更新需重启原 Python 服务并刷新原端口，历史端口记录不代表本轮已重启。

页面保存会比较打开表单时的配置快照；其他窗口或 CLI 修改配置后，网页拒绝覆盖，提示重新加载。关键词、来源、临时时长及同目标兴趣修订不切换档案；明确切换目标或特征解释规则变化才隔离。网页不提供密钥编辑界面。

## 实现与边界

- `info_agent/web.py`：本地 HTTP/API 适配、独立请求数据库连接、生成线程、受控反馈与设置保存。
- `info_agent/web_assets/`：静态 HTML、CSS、JavaScript，无第三方 CDN。
- `main_gui.py`：编辑器入口。
- `tests/test_web.py`：临时数据库与注入工作流测试，不调用付费模型。

接口包括 GET `/api/state`、GET `/api/runs/{id}`、GET `/api/runs/{id}/download`，以及 POST `/api/run`、`/api/profile`、`/api/feedback`、`/api/undo`。

写请求需要页面会话令牌，校验 Host 和 Origin，不开放 CORS；只提供明确列出的静态资源，不暴露项目文件系统。来源内容按文本转义，来源链接仅接受 HTTP/HTTPS。模型与来源异常采用服务端安全错误码和说明，保留已知阶段／类型及可选计数；不将原始异常、密钥或内部请求信息送给浏览器。

网页复用业务层，而不是重写筛选、排序或学习算法。实际 RSS 和模型可用性仍依赖既有隧道与配置；如果服务未连接，页面展示失败状态和历史记录，不伪造成功。
